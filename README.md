## 🚀 Featured Projects

**PathweaverAI: AI-powered personalized learning platform**
Architected a 9-phase asynchronous course-generation pipeline on BullMQ/Redis workers (curriculum design, video search and semantic scoring, transcript extraction, quiz generation) with real-time progress over Server-Sent Events. Multi-provider LLM layer (Gemini, OpenAI, Groq, Mistral) that picks models by task, latency, and cost, with BYOK keys encrypted using AES-256-GCM. 30+ model PostgreSQL schema plus an atomic double-entry ledger with an HMAC hash chain for tamper-evident audit records.
`Next.js` `TypeScript` `PostgreSQL` `Redis` `BullMQ` `Prisma`

**AlgoJeet Pro: local-first coding interview prep platform**
Offline-capable workbench with 3,350+ LeetCode problems mapped to 650+ companies, with SM-2 spaced repetition, code execution, and analytics running entirely in the browser. Multi-runtime execution: Pyodide (WebAssembly) for Python, isolated Web Workers for JavaScript, and a sandboxed server-side runner for C++ and Java with rate limiting and circuit breakers.
`Next.js 15` `React 19` `WebAssembly` `Dexie.js` `Supabase`

**Realtime Collaborative Code Workspace** *(open source, in development)*
Event-driven, microservice-style code editor: Apollo GraphQL API, Socket.IO and Hocuspocus/Yjs (CRDT) sync, Kafka/Redpanda workers, and Keycloak OIDC auth, targeting Kubernetes. AI code review and semantic search are designed around self-hosted open models (vLLM, TEI) with no third-party LLM APIs.
`Next.js` `GraphQL` `Yjs` `Kafka` `Kubernetes`

**Paradox ERP: multi-tenant enterprise platform**
Accounting, deals, CRM, and operations dashboard with PostgreSQL Row Level Security for database-level tenant isolation. Forms validated with React Hook Form and Zod, backed by 30 Vitest test files and Playwright E2E tests.
`Next.js` `Supabase` `PostgreSQL` `Zod` `Vitest` `Playwright`
